# OP 籌碼贏家 Pro — 台指選擇權主力籌碼與三線量化看盤 APP (參照 www.op-win.com)

參照 `www.op-win.com`（籌碼贏家）之核心量化指標與功能架構所打造的跨平台（電腦大螢幕 + 手機隨身看盤 PWA / Android APK）台指選擇權籌碼分析系統。

---

## 核心功能與線圖模式

1. **📊 籌碼即時線圖（三種經典三線模式一鍵切換）**：
   - **1. CP 差額圖**：
     - 🟢 **綠線 (CP 差額值)**：判斷選擇權籌碼多空口數之總額變化。
     - 🔴 **紅線 (Call 買權)**：位於零軸之上表示買進 (`BC` 看大漲)；位於零軸之下表示賣出 (`SC` 看不漲/壓力)。
     - 🔵 **藍線 (Put 賣權)**：位於零軸之上表示買進 (`BP` 看大跌)；位於零軸之下表示賣出 (`SP` 看不跌/支撐)。
   - **2. 台指期多空成本圖**：
     - 🔴 **紅線 (多方成本)**：當多方有量進場時紅線即會出現接手，站上短多成本時偏多看。
     - 🔵 **藍線 (短空成本)**：跌破藍線時偏空看。
     - 🟢 **綠線 (多空成本)**：線上偏多、線下偏空。
   - **3. 主散籌碼對決圖**：
     - 🔴 **主力 (紅線)**：主力積極買進時為正數，反之賣出為負值。
     - 🔵 **散戶 (藍線)**：顯示散戶籌碼動向。
     - 🟢 **市場趨勢 (綠線)**：顯示整體市場合力方向。
2. **🎯 選擇權籌碼 T 字報價與波段支撐壓力佈局表**：
   - 自動計算並標示 **Call 最大未平倉壓力天花板**、**Put 最大未平倉支撐地板**、**莊家最大痛點 (Max Pain)** 與 **P/C Ratio**。
   - **支援自訂波段累積日期**（當日 1 日 / 近 3 日累積 / 週選波段 5 日 / 月選波段 20 日）。
   - **點擊任一履約價位**：立即彈出該履約價的**「當日分時權利金量價曲線」**與**「近一週 (7日) 未平倉累積趨勢圖」**。
   - 內建**三大法人（外資、自營商、投信）選擇權 BC / SC / BP / SP 口數與契約金額結構表**。
3. **⏪ 盤勢回顧與 1分 / 5分 / 15分 K 線逐步復盤模擬演練**：
   - 支援挑選特定歷史或當日盤勢，以 **1分 / 5分 / 15分 K 線** 逐步播放、單步前進/後退或拖曳時間軸復盤，並與下方 CP 差額圖 / 主散圖即時同步連動。
4. **📑 盤勢分析報告 & 🎓 選擇權基礎教學 (`BC / BP / SC / SP` 互動損益試算器)**。
